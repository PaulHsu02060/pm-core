# PM-Core 離線版（build 20260830-4f7a4153）

## 給使用者：兩步就會動

1. 把 `pm-core-offline.html` 存到電腦上任何一個位置（建議固定一個資料夾，例如 `D:\PM-Core\`）
2. **用瀏覽器打開它**（雙擊即可）

就這樣。**不需要安裝、不需要網路、不需要帳號**，也不需要這個資料夾裡的其他檔案——
系統本體全部都在那一個 html 裡（樣式、字型、Excel／PDF 函式庫都內嵌了）。
（旁邊那幾支 `.cmd`／`.ps1` 是**選配**，只有要「錄音自動變逐字稿」才會用到，見下面那一節。）

## 要更新版本時

**直接用新的 `pm-core-offline.html` 覆蓋舊的，然後打開。**
資料不會被蓋掉，也不必事先備份；檔案放在哪個資料夾、改成什麼檔名都沒關係。
換版後第一次開啟，系統會主動告訴你「資料原封不動都在（N 個專案 / M 筆任務）」。

## 你的資料存在哪

存在**你這台電腦的瀏覽器**裡，不會上傳到任何地方。因此：

- 換另一個瀏覽器（例如 Chrome 換成 Edge）**看不到原本的資料**——那是兩個獨立的儲存空間。
- 要換電腦或換瀏覽器，先在「設定 → 資料與備份」按「⬇ 下載 JSON 備份」，到新環境用「⬆ 匯入還原」帶過去。
- 清除瀏覽器資料（包含「Cookie 和其他網站資料」）會一併清掉，請先備份。

## 想讓錄音自動變逐字稿（選配·不用也完全不影響）

系統本身**不做**錄音轉文字（那要跑 AI 模型，一個網頁揹不動）。做法是免費的單機工具在旁邊接手，全程在你的電腦上跑、**錄音檔不外傳**。

**要裝就一件事：雙擊這個資料夾裡的 `setup-transcribe.cmd`。**

它會自己下載轉檔程式、解壓到桌面、**判斷你這台該用顯卡還是 CPU**、先把模型抓好、建好桌面捷徑，然後直接開始監看。你不用打指令、不用選任何東西。

- ⚠ 要下載約 1.4 GB 的程式與 0.5～1.5 GB 的模型，**這是唯一需要連網的一步**；裝完之後轉檔全程離線（拔網路線照樣能轉）。
- 之後每天開工只要雙擊桌面的「**開始自動轉逐字稿**」，讓黑色視窗開著就好。
- 用法：在系統的逐字稿視窗按「🎙 錄音」→ 開完會按停止 → 音檔自動下載 → 黑色視窗自己轉完並嗶兩聲 → 把產生的 `.txt` 拖回逐字稿視窗。

**不想裝、或公司電腦不給裝都沒關係**：音檔照樣會下載，你自己轉成 `.txt` 再拖進來，功能完全一樣。
不想再看到相關提示，到「**設定 → 資料來源 → 錄音後怎麼轉**」選「**不使用**」，說明與入口就會收起來。

## 這個資料夾裡的其他檔案

| 檔案 | 給誰 | 說明 |
|---|---|---|
| `pm-core-offline.html` | **使用者** | 系統本體。**只有這個檔要發給同事。**（要用錄音自動轉逐字稿，再加下面那組腳本。） |
| `setup-transcribe.cmd` | 使用者·選配 | **一鍵安裝**：要用錄音自動轉逐字稿，雙擊這一支就好。上面那一節。 |
| `start-watch-transcribe.cmd` | 使用者·選配 | 每天開工啟動監看（安裝時會在桌面建好捷徑，通常用不到這支）。 |
| `setup-transcribe.ps1`／`watch-transcribe.ps1`／`transcribe-lib.ps1` | 使用者·選配 | 上面兩支 `.cmd` 實際跑的內容。**五支是一組，要放在同一個資料夾**，少一支就跑不動。 |
| `轉逐字稿工具.zip` | 使用者·選配 | 上面那五支的壓縮包。**只拿到 html 一個檔的同事**，可以在系統裡「錄音已存檔」的視窗或教學窗按「⬇ 下載自動轉檔工具」拿到**同一份**。 |
| `詞彙表.txt` | 使用者·選配 | 把公司常出現、轉逐字稿老是打錯的詞（人名、料號、專案代號）寫進去，一行一個或用空白隔開，轉出來會準很多。改完存檔，把那個黑色監看視窗關掉重開就生效。整份都是說明也沒關係——那時會用內建的預設詞。 |
| `離線版-MIS資安說明.md` | 資訊部門 | 資料流向說明＋兩分鐘自行驗證步驟（F12 → Network 對外請求應為 0）。 |
| `pm-core-offline-MIS審核包.zip` | 資訊部門 | 這個資料夾的整包，送審一次給一個檔就好。 |

審核重點：本系統零對外連線、資料只存本機瀏覽器——請照資安說明用 F12 Network 實測確認
（這是行為層鐵證，不需逐行讀碼）。要審的程式碼也全部在那個 html 裡，不需另外調閱。
