# PM-Core 離線版 — 資安說明（給 MIS / 資訊部門）

> 一頁講清楚：這個工具是什麼、資料流向、如何自行驗證。
> 檔案：`pm-core-offline.html`（單一 HTML 檔·自帶全部程式與字型·約 7MB）
> 同包另附五支**選配**的轉逐字稿腳本（預設不會執行·其中一支安裝用的**會連 GitHub 下載第三方工具**·說明見末節「同包附的五支腳本」）。

## 這是什麼

專案管理個人工具（排程／進度／負荷計算／報表）。**純前端網頁單檔**：用瀏覽器開啟（雙擊或 `file://`），不安裝任何軟體、不需要管理員權限、不建立任何服務或排程工作。

## 資料流向（核心）

| 問題 | 答案 |
|---|---|
| 會連外網嗎？ | **不會。零對外連線。** 所有程式庫、字型、圖示全部內嵌在單檔內；雲端同步／帳號登入／**雲端**語音轉譯在此版本已整組移除。唯一例外＝下方「選配功能：AI 報價單辨識」——**未貼入金鑰前不會發出任何對外請求**，且可一鍵停用。 |
| 有錄音功能嗎？ | 有，但**只在本機**：按「🎙 錄音」用瀏覽器內建的錄音介面（會先向使用者要麥克風權限），停止後**直接下載成音檔**存到這台電腦，**不上傳任何地方**——這條路徑一樣是零對外連線，可用下方 F12 方法實測。要把音檔變文字＝末節那組選配腳本，轉檔全部在本機跑（只有安裝那一次要連網下載工具）。 |
| 資料存在哪？ | **只存在這台電腦的瀏覽器 localStorage**。不上傳、不同步、不落地到任何伺服器。 |
| 備份怎麼做？ | 使用者手動「下載 JSON 備份」存到公司核准的位置（公司硬碟／公司雲端）。檔案不離開公司環境。 |
| 需要帳號嗎？ | 不需要。無登入、無外部身分驗證。 |
| 會自動更新嗎？ | 不會。更新＝人工替換新的單檔（同樣流程再審一次即可）。 |

## MIS 如何自行驗證（兩分鐘）

1. 用瀏覽器開啟 `pm-core-offline.html`。
2. 按 `F12` → 切到 **Network（網路）** 分頁 → 重新整理頁面。
3. 確認清單中**沒有任何 `http(s)://` 對外請求**（只有 `file://` 本身）。
4. 可再實際操作幾個功能（建任務、開報表）——Network 持續為零。

這不是口頭承諾：單檔內沒有任何 `<script src="http…">` / `<link href="http…">` 外部資源引用（打包流程有自動防呆，殘留任何外部引用即中止產出），對外請求「結構上」不存在。

## 選配功能：AI 報價單辨識（未貼金鑰＝不連線·可一鍵停用）

系統設定頁有一個「離線版 AI 辨識（選配）」開關（預設啟用）。**啟用不等於連線**：使用者必須自行取得並貼入 AI 金鑰，系統才具備連線能力——**沒有金鑰時，系統不會發出任何對外請求**（可實測驗證）。

- **實際連線的時機**：只有使用者貼了金鑰、且按「智慧匯入單據」辨識供應商報價單的當下，會對 **`generativelanguage.googleapis.com`（Google AI）這一個網域**發出請求，內容為該張報價單影像；其餘所有功能仍然零外連。
- **不會發生什麼**：公司彙整後的專案資料、會議錄音／逐字稿**不會**經由此連線送出（雲端語音轉譯在離線版整組移除；本機錄音與本機轉逐字稿都不隨此開關連線）。
- **可稽核**：同樣可用 F12 → Network 檢視——除辨識當下對上述單一網域的請求外，不應出現任何其他對外連線。
- **管控建議**：若貴部門不允許，請使用者在設定頁將此開關改為「停用」（即回完全零外連），並且不核發／不貼入 AI 金鑰——沒有金鑰，連線在能力上就不存在。設定頁亦附有「請先與資訊部門確認」提示。

## 同包附的五支腳本（選配·預設不會執行·會議錄音不出這台電腦）

把會議錄音轉成逐字稿用的一組腳本。**不裝、不跑，系統一切功能照常**（使用者自己把音檔轉成 `.txt` 再匯入即可）。系統設定裡也有一個「**不使用**」選項，選了就把相關入口整個收起來。

| 檔案 | 做什麼 | 會不會連外網 |
|---|---|---|
| `setup-transcribe.cmd`／`.ps1` | **一鍵安裝**：下載並設定好轉檔程式 | **會**（只有這一支·詳下） |
| `start-watch-transcribe.cmd`／`watch-transcribe.ps1` | 日常使用：盯資料夾、把新錄音轉成文字 | **不會**（零對外連線） |
| `transcribe-lib.ps1` | 上面兩支共用的判斷函式，不單獨執行 | 不會 |

**同包還有一個不是腳本的檔：`詞彙表.txt`**（純文字·選配）。
使用者可以把公司常出現的專有名詞（人名、料號、專案代號）寫進去，轉逐字稿時當作辨識提示，讓那些詞不容易被聽錯。
**它只被本機的轉檔程式當作提示文字讀取，不會被送到任何地方**；不填、或整份都是說明文字，系統會改用內建的預設提示。
內容全由使用者自己決定，我方不預先填入任何公司資料。

| 問題 | 答案 |
|---|---|
| 什麼時候會執行？ | **只有使用者自己雙擊那個 `.cmd` 的時候。** 不安裝、不註冊服務、不建立排程工作、不開機自動啟動、**不寫入登錄檔**（只**讀取**「下載資料夾在哪」這一個系統設定）——關掉那個視窗就完全結束。安裝腳本會在桌面建一個捷徑（`.lnk`），僅此而已。 |
| 需要管理員權限嗎？ | 不需要。腳本以目前使用者身分執行（`-ExecutionPolicy Bypass` 只作用於這一次執行，**不改變機器的原有政策**）。 |
| **安裝腳本連去哪裡？** | **只有兩個地方，而且只在安裝當下**：①`github.com`／`objects.githubusercontent.com`（下載轉檔程式壓縮檔，約 1.4 GB）②該程式第一次執行時向 `huggingface.co` 下載語音辨識模型（約 0.5～1.5 GB）。**不上傳任何東西**——沒有帳號、沒有遙測、不送出任何本機資料。 |
| 日常使用會連網嗎？ | **不會，零對外連線。** 監看腳本只做兩件事：盯著「下載」資料夾有沒有新的錄音檔、把檔案餵給本機的轉檔程式。可實測：**拔掉網路線照樣轉得出來**。 |
| 錄音會被送出去嗎？ | **不會。** 音檔、逐字稿全程只在這台電腦的硬碟上，沒有任何上傳行為。 |
| 會開監聽埠嗎？ | **不會**，這是刻意的設計選擇（開埠的做法評估後未採用）。 |
| 那個「轉檔程式」是什麼？ | 第三方免費工具 **Faster-Whisper-XXL**（來源：GitHub `Purfview/whisper-standalone-win`，語音辨識模型為 OpenAI Whisper，皆為開源授權）。**不在本包內**，解壓即用、免安裝、免管理員權限。它是**未經數位簽章**的執行檔，下載與執行前請依貴部門政策審核。 |
| 不核准可以嗎？ | **可以，而且不影響系統。** 不核准就不要跑那支安裝腳本；使用者在系統設定裡把「錄音後怎麼轉」改成「不使用」，相關提示就不再出現。錄音與逐字稿匯入都照常。 |
| 怎麼確認下載到的檔沒被掉包？ | 安裝腳本會比對**檔案大小**（以 GitHub 官方公布的位元組數為準）與**寫死的 SHA-256 指紋**，任一不符就中止並保留檔案供檢查。 |
| 會動到憑證設定嗎？ | **不會修改任何東西。** 貴公司若有 HTTPS 檢查機制（本機實測為 Kaspersky Endpoint Security），該工具內建的下載元件不讀取 Windows 憑證存放區，會導致模型下載失敗。腳本的處理方式是：**唯讀**匯出「這台 Windows 已經信任的根憑證」成一個暫存檔，僅供該次執行的子程序使用。**不新增、不刪除、不修改任何憑證，也不會停用憑證驗證**（腳本內明文禁止該做法，並有自動化測試防止日後被改成停用）。 |
| 程式碼能審嗎？ | 能。五支都是**純文字**、可直接用記事本開啟閱讀（含完整中文註解），不含任何編譯後的二進位內容。 |

## 補充

- **來源與版本**：檔案開頭註解帶有 build 版號（日期＋版本代碼），可核對目前使用版本。
- **程式碼**：為保護智慧財產已壓縮（去空白註解），但行為可由上述 Network 驗證完整確認。
- **移除乾淨**：不想用時，刪除 HTML 檔＋清除該瀏覽器分頁的網站資料即可，系統不留任何其他痕跡。
